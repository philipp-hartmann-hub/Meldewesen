# Workshop A2 eMeldewesen – Agenda (JVA-Bedienstete, Mehr-JVA-Kern)

Ziel: Gemeinsames Verständnis der Meldeprozesse, Priorisierung für das Lastenheft, Erfassung von JVA-Abweichungen.  
Teilnehmer: Bedienstete aus mehreren JVAs (idealerweise je JVA aVD/Stationsleitung und VAL/AL vertreten), optional IT/Moderation.

**Vorbereitung:** Beamer oder großer Monitor, Testzugang zum Prototyp (oder Screenshots), Moderationskarten, Protokollführung.

---

## Varianten (Wählen Sie eine Dauer)

### Variante A – 90 Minuten (Fokus Kern)

| Zeit  | Block | Inhalt |
|-------|--------|--------|
| 0–10  | Begrüßung | Ziel Workshop, keine Entscheidung über Zielsoftware |
| 10–25 | Kontext | A2 vs. A1, was der Prototyp kann und bewusst nicht kann |
| 25–45 | Live oder Screens | Dashboard, Rolle wechseln, eine Meldung durchklicken |
| 45–70 | Breakout oder Plenum | „Was fehlt uns im Alltag?“ – Moderation sammelt Stichworte |
| 70–85 | Mehr-JVA | Kurz je JVA: eine Abweichung oder „keine“ |
| 85–90 | Abschluss | Nächste Schritte, offene Punkte, Dank |

### Variante B – 120 Minuten (+ Strafanzeige vertiefen)

| Zeit   | Block | Inhalt |
|--------|--------|--------|
| 0–10   | wie A | |
| 10–30  | Kontext + Rollen | Kurzmatrix an der Wand/Slide: wer darf was |
| 30–55  | Prototyp | Meldung anlegen (wenn UI da) oder Fachlicher Papierablauf |
| 55–85  | Strafanzeige | Pflichtfelder, Reihenfolge ERV/beBPo/eGPA, Vier-Augen |
| 85–110 | Mehr-JVA | Pro JVA max. 5 Min: Abweichungen + gemeinsamer Kern |
| 110–120| Abschluss | Prioritätenliste Top 5, Verantwortliche |

### Variante C – 180 Minuten (+ alle Meldungstypen grob)

| Zeit   | Block | Inhalt |
|--------|--------|--------|
| 0–15   | Begrüßung + Kontext | |
| 15–45  | Rollen und Rechte | Diskussion Matrix, Anpassungswünsche |
| 45–90  | Meldungstypen | Pro aktiven Typ (Strafanzeige, interner Vorfall, Gericht) 15 Min Fachprozess |
| 90–120 | Inaktive Typen | Soll-Sicht „in Planung“ in der UI – reicht das? |
| 120–150| Mehr-JVA-Abweichungen | Strukturiert nach Thema (Bezeichnungen, Eskalation, Empfänger) |
| 150–175| Abnahme-Szenarien | Workshop: **fachliche Plausibilität**; Regression später alle `A2-F-TST-…` (siehe Kap. 9) |
| 175–180| Nächste Schritte | |

## Moderationshinweise

- **Sprache:** Alltag der Anstalt, keine IT-Spezialbegriffe ohne Erklärung.
- **Protokoll:** Pro Aussage: „Wer sagt was für welche JVA?“ bei Abweichungen markieren.
- **Konflikte:** Nicht im Workshop lösen – als „Lastenheft offener Punkt“ mitnehmen.
- **Datenschutz:** Keine echten personenbezogenen Daten im Protokollbeispiel verwenden.
